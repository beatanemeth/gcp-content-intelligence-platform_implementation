# Terminal output of the real GCP run

> **Real GCP, 2026-10-20:** the output of the [runbook](../runbook.md) commands, saved with `<command> 2>&1 | tee <file>`; a rerun appended to the same file with `tee -a`. The results and findings are in [progress.md](../for_AI/progress.md), step 9, part 2.

- **Order:** the prefix is the runbook step (`s05a` = step 5, first file); within a step, the dummy run comes before the full dataset.
- **Commands:** ready for the next run, from the repository root. They write the records under the names below into the git-ignored `.build/real-run/`. Where the run differed (a rerun, a missing flag), the table gives the corrected command and says what happened.
- **Placeholders:** `<project-id>`, `<project-number>`, `<billing-account-id>` and `<email>` replace the real values.
- **Trimmed:** `s05a-plan.txt`, `s05b-apply.txt` and `s10a-destroy.txt` keep the resource list, the progress lines, errors and totals; the resource attributes are removed. Each file says so in its first line.
- **Author names:** replaced in `s09-full-top_posts_per_category.csv` ("Author 1"), as in the step 8 publishing rule.
