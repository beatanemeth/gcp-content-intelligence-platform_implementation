# Rules: working with the maintainer

## Profile

- **Google Professional Data Engineer** certified.
- Strong in **systems thinking**, Python, Docker and API-based ETL. Works on Linux.
- Writes in English as a second language.

## How to support the maintainer

- **Terraform:** the maintainer is learning it. Explain the reasoning behind each resource, argument and command, not just the code.
- **GCP:** the maintainer knows GCP from certification; this project is the hands-on practice. Challenge that knowledge before writing GCP code: ask one guiding question (for example, which role or setting fits, and why). Then write the code and explain how it answers the question.
- **Wording:** use plain, precise English.
